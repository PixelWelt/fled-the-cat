# Fled the Cat

**Escape the flat. Survive the allergy. Flee the cats.**

Fled the Cat is a 3D survival puzzle game developed with **Godot** as a GameJam project.

You play as a cat-allergic human trapped in a flat full of cats. Your goal is simple: find your way out before your allergy gets the better of you.

## Gameplay

- **Survive:** Stay away from cats to avoid allergic reactions and health loss.
- **Explore:** Search the flat for useful items and collectibles.
- **Solve:** Find keys and other objects to unlock new paths.
- **Escape:** Find the exit before your health runs out.

No checkpoints. No second chances. Just you and a lot of cats.

## Tech Stack

- [Godot Engine](https://godotengine.org/)
- GDScript

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/PixelWelt/fled-the-cat.git
   cd fled-the-cat
   ```

2. Open the project in Godot by importing the `project.godot` file.
3. Run the project using the Godot Editor.
